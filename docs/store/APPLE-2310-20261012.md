# Apple review correction — Guideline 2.3.10

## Correction

- The phone download promotion, badges and store trademark notice render only in a web browser. They do not render inside either Capacitor app.
- Store UI stays absent during server rendering and hydration until the native bridge identifies the platform. This also covers iPad; it does not rely on mobile user-agent detection.
- The rating card in iOS can only link to the Apple store. An Android-only link never activates that card in iOS. Without a matching published link, installed apps show no coming-soon rating promotion.
- The public support answer about using NITIDO on a phone contains no competing-store reference or development terminology.
- The website retains its existing store promotion. Android ratings retain their own store link when configured.
- The prepared iOS project build number is 17, marketing version 1.0. The existing Apple preflight must verify that 17 exceeds the current authenticated maximum before signing.
